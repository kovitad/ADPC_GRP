Source data

Review the files in the read-only source folder and prepare evidence for the data team: what arrived, how the automated checks interpreted it, and what needs confirmation.

Delivered source data — not a GRP result. The Data Science delivery is accepted as the source input. This page reads it before GRP registers dataset versions and applies an assessment method; its findings are for data preparation and are not sent to SIG.

For another local dataset, make a new folder under .local/data-in, copy the files into it, refresh this page, choose General GIS data, and select that folder. The source mount is read-only, so validation cannot alter the files. Supported layers are Shapefile, GeoJSON, GeoPackage and GeoTIFF.

Want to see the files on a map? Preview one district — outline, shelters and flood depth, with the warnings beside it. Ready to register the accepted baseline? Open the Data library.
