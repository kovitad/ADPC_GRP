# Mangrove 360 web assets

Copied unchanged from `docs/adhoc/mangrove360-brand-kit-v1/assets/`, version 1, dated
23 October 2026. The source kit says the images were created with built-in `image_gen`; conceptual
coastlines are fictional and must not be presented as geographic evidence. Display guidance and
provenance are in the source kit's `HOW_TO_USE.md` and `asset-manifest.json`.

The application preserves the source PNG files and their SHA-256 fingerprints. Do not replace the
logo silently, stretch these images, or use the decorative coastlines as evidence, a land boundary,
a hazard result, a financial forecast, or a carbon-credit estimate.
