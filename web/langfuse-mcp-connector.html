Prepare a Langfuse MCP connector

Generate the Basic Authorization value required by Claude without sending or storing the Langfuse project keys.

Connection details

Connector name
grp-langfuse
MCP URL
https://langfuse-risk-servir.adpc.net/api/public/mcp
Authentication
No sign-in, with an Authorization request header

Use keys from the same GRP Evaluation project. They remain only in this page's memory and are cleared immediately after copying.

Add the copied value to Claude

  1. Open Claude's custom connector settings and select No sign-in.
  2. Under Request headers, select Add header.
  3. Set the header name to Authorization and paste the generated clipboard value into the header-value field.
  4. Leave transport set to automatic, save the connector, then overwrite the clipboard.

Header name: Authorization
Header value: Basic <generated value>

Treat the copied value as a secret

  • Paste it only into Claude's Authorization request-header field.
  • Do not paste it into chat, email, screenshots, documents, logs, or Git.
  • Overwrite the clipboard after saving the connector.
  • Revoke the project key immediately if either key or the generated value is exposed.
